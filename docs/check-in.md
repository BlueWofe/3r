# 本人簽到與補簽

教師可從「今天的行程」或行事曆選擇課程、開啟詳情後操作本人簽到。兼具管理員與教師身分時，本人簽到直接使用自己的指派，不必選同工或填寫管理補登原因。

行事曆預設顯示「我的課程」。具有查看所有排課權限者可切換全部或指定教師；一般教師只能查看自己的範圍。月／週點日期、議程點課程均先開啟當日行程列表；列表以「我的課程」標示本人的有效指派，選擇行程後才開唯讀詳細資料。

詳情顯示課程、班級、監所與地址、上課位置、日期時段、參與人數、老師指派及簽到狀態。本人或具出勤管理權限者可看固定大小的簽到照片縮圖；其他老師的照片不會透過縮圖要求下載。私人照片下載仍由伺服器重新檢查權限。

管理員按詳情底部「編輯」後，才在同一視窗顯示完整場次欄位與管理操作；「返回詳細資料」可回到唯讀狀態。教師詳情保留本人簽到／補簽；尚可異動的行程另以「請假／換課」進入服務操作。

- 台北日期的當日整天均可「簽到」，課程結束時間不限制本人簽到。備註與照片均選填。
- 已過日期的本人行程可「補簽」，必須填寫原因，照片選填。從行事曆的月／週日期選擇行程後操作。
- 未來行程不能提前簽到；已請假、已取消、已被替換或已有出勤記錄時不提供本人簽到按鈕。
- 成功後重新載入行程，顯示伺服器保存的實際操作時間（Asia/Taipei），不以授課日期／開始時間取代簽到時間。重整頁面不會再提供重複簽到。

本人操作使用 `POST /api/v1/assignments/{id}/attendance` multipart：`mode=self`、`reason`（當日選填、過日必填）、`photo`（選填）。管理補登使用 `mode=admin`，需管理權限及原因；本人簽到與管理補登是不同操作。

出勤資料包含 `kind: check_in | late_check_in | admin_adjustment`、`at`（伺服器實際時間）、`service_date`（原授課日期）、`present`，有照片才提供 `photo_id`。本人簽到／補簽的 `present` 為 true。

`tests/e2e/check-in-mock.ui.spec.ts` 使用合成同工與課程，攔截全部 API，不寫入真實資料庫或修改任何人的出勤。時間固定為台北 2026-10-02 21:30，課程早上 10:00 已結束；桌面及手機驗證本人簽到、管理員兼教師、補簽原因、選填照片、重複操作、不可簽到狀態與更新後的實際時間。手機主要操作亦以 320px 寬度驗收。
