# 消息、見證與圖文編輯

首頁「更新的足跡」讀取 `/api/v1/public/news?limit=3`，按照發布時間由新到舊顯示最多三篇；同時間以 ID 倒序。消息及見證共用文章資料，分類可選「最新消息」或「見證分享」。每個節點顯示日期、分類及文章標題，連往 `/news/{id}`。無內容及連線失敗分別呈現空白提示與錯誤提示，不補入虛構故事。

內容管理沿用 `content.read/create/update/publish.all` 權限。文章與協會頁面支援所見即所得編輯，產品仍由獨立產品管理維護。編輯器與公開頁共用文章樣式，支援標題、粗斜體、清單、引言、連結及公開圖片。

`contents` 的新增欄位：

| 欄位 | 定義 |
| --- | --- |
| `author_name` | 公開署名，最多 100 字；新建未填使用編輯者名稱，舊文章預設「協會編輯部」 |
| `published_at` | ISO 8601 發布時間，後台以臺北日期／時間輸入；首次發布未填使用當下時間，普通編輯保留原發布時間 |
| `body_format` | `text` 或 `html`；舊內容維持純文字，經圖文編輯器編輯後保存為 HTML |
| `body_html` | 公開 API 產生的安全 HTML，不接受客戶端直接設定；純文字轉義後保留段落與換行 |

只有狀態為 published 且已到發布時間的文章，才可由公開列表、文章詳情及搜尋取得。文章頁顯示分類、標題、作者及臺北發布日期與時間。

HTML 由伺服器白名單清理；只保存支援的排版、連結及圖片，不保存 script、iframe、事件屬性或任意樣式。公開回應再次清理舊資料。內文圖片僅接受資源庫中的公開圖片；私人附件不會因文章引用而變更權限。公開搜尋以文字內容比對，不搜尋 HTML 標籤。

原有純文字 API 客戶端繼續可用，不要求重新輸入舊資料或清空資料庫。
