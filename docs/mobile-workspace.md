# 手機工作台與官網切換

手機的主要工作是查看安排、打卡、回覆代課及處理異動。後台資訊列表在窄螢幕以帶欄位名稱的卡片呈現，桌面保留便於比較的表格；不以隱藏溢出內容代替可操作的版面。長標題、網址與操作按鈕需換行，表單和彈出視窗不得超出螢幕。

手機與桌機工作台的左上協會 Logo 可點選回到官網，移除重複的「回到官網」文字按鈕。官網與工作台使用同一登入狀態，不必登出或切換帳號。「我的服務」與「管理工作台」為兩個獨立選單，使用圖示搭配文字；手機一次展開一組，以兩欄功能入口縮短選單，進入頁面後收合。一般會員、志工及兼任管理員看到的選項依實際權限決定；導覽切換不授予新權限，API 仍逐次檢查。

角色設定的權限使用中文說明，依選單分類，提供全域與分類的全選／全不選及已選數量。底層權限識別與授權規則不變；共用權限的選單明確合併標示。系統管理員固定完整授權，介面另有說明。取消編輯不會改動原有角色的勾選陣列。

驗收涵蓋 320px 及 390px 寬度：列表與表單無頁面水平溢出、卡片保留欄位與操作、選單能開關、回官網後仍登入且可回工作台、一般會員不顯示管理入口。

設計參考：[GOV.UK 小螢幕單欄布局](https://design-system.service.gov.uk/styles/layout/)、[GOV.UK 資料摘要卡片](https://design-system.service.gov.uk/components/summary-list/)、[Carbon 資料表與觸控操作](https://carbondesignsystem.com/components/data-table/usage/)。
