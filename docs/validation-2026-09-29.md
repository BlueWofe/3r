# 2026-09-29 整合驗收

本機 `r3-dev`、PostgreSQL 17、Redis 7，全部使用合成資料與模擬外部介接。

- PHPUnit：54 項測試、315 個斷言通過。涵蓋多角色聯集、立即撤權、最後管理員、OTP 限流、排課狀態機、檔案權限、表單版本、模擬奉獻冪等與統計。
- Playwright：18 項通過，含 10 項真實 PostgreSQL API 測試與 8 項桌機／iPhone UI 測試。

- Nuxt 型別檢查與 Docker 前後端建置通過。
- 私人上傳檔案與資料庫紀錄在重啟所有 `r3-dev` 容器後保留；匿名下載仍拒絕，既有登入有效。
- PostgreSQL 實際 dump 並還原到新建的驗證資料庫，會員、通用資料及老師安排筆數一致；驗證後只移除該暫存資料庫。
