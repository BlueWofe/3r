# 商品分類、洽詢與通知

公開商品列表支援 category 篩選及 limit，先篩選已發布商品再套筆數；回傳 categories 為所有已發布商品分類，草稿商品分類不得公開。官網產品頁提供全部商品與各分類入口，URL 保存分類，可重新整理或分享；無結果顯示明確空狀態。商品仍只展示與數量報價，不新增購物車或付款。

商品上方採使用者提供的企業 CSR／教會節慶禮盒大宗認購文案。「大宗洽詢」與「登記試吃」分別導向聯絡表單的新分類；後台可按相同分類篩選。

聯絡表單以同源 CSRF、隱藏誘捕欄位、送出時鎖定、每 IP 每分鐘 20 次／每小時 100 次限流及重複內容去重降低大量灌入。同內容在 10 分鐘內改用另一 UUID 重送，回相同收件編號，不重複建立留言或通知；每個使用過的 UUID 仍綁定原內容，不同內容回 409。不得把無效／未保存提交顯示為成功，不使用假 CAPTCHA。正式外部 CAPTCHA 尚未介接；現有防護不能保證完全阻擋自動化垃圾訊息。

工作台通知收件匣提供全部、產品通知、課程通知、小組消息、其他聯絡分類及未讀數字。通知類別 API 值為 product、course、message、contact。新聯絡表單只通知目前具有 contacts.read.all 的有效同工，通知文字不複製姓名、電話或留言；試吃與大宗洽詢屬產品通知，其他聯絡表單屬其他聯絡。商品訂單屬產品通知，小組消息屬小組消息。課程異動只通知有效系統管理員、異動前後受影響的授課老師及指定代課邀請對象；有全排課權限但未被指派的同工不因一般排課管理而收到課程通知。例行管理異動留在稽核紀錄。

GET /notifications 每次依目前登入者和關聯資料重新計算可見性，回傳 {data,unread_count}。POST /notifications/{id}/read 及 POST /notifications/read-all 只讀取目前帳號有權檢視的自有通知；批次已讀不修改其他帳號或已失去權限的項目。通知目的連結由後端依目前權限產生。撤銷成員、指派或相關資料權限後，舊通知不得再提供連結或資料。工作台收件匣和小鈴鐺同步顯示未讀數；點通知標示已讀後導向對應課程、代課邀請、小組文章、訂單或聯絡訊息。手機版分類可水平操作，Logo 與工作台選單仍可使用。
