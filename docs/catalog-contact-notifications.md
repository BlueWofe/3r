# 商品分類、洽詢與通知

公開商品列表支援 category 篩選及 limit，先篩選已發布商品再套筆數；回傳 categories 為所有已發布商品分類，草稿商品分類不得公開。官網產品頁提供全部商品與各分類入口，URL 保存分類，可重新整理或分享；無結果顯示明確空狀態。商品仍只展示與數量報價，不新增購物車或付款。

商品上方採使用者提供的企業 CSR／教會節慶禮盒大宗認購文案。「大宗洽詢」與「登記試吃」分別導向聯絡表單的新分類；後台可按相同分類篩選。

聯絡表單以同源 CSRF、隱藏誘捕欄位、送出時鎖定、IP 限流及重複內容去重抵擋大量灌入。不得把無效／未保存提交顯示為成功，不使用假 CAPTCHA。正式外部 CAPTCHA 尚未介接；現有防護不能保證完全阻擋自動化垃圾訊息。

工作台小鈴鐺提供目前帳號可查看的通知、未讀數字與操作連結。新聯絡表單只通知目前具有 contacts.read.all 的有效同工，通知文字不複製姓名、電話或留言。小組消息通知亦保持通用文字。列表及快速連結由後端重新套權限；成員或權限撤銷後不得透過舊通知取得資料。點選可標示已讀並前往對應課程、代課邀請、小組文章或聯絡訊息；手機保持 Logo 與兩個工作台選單可操作。
