# 官網改版驗收操作

這組 Playwright 驗收檢查首頁、協會介紹與奉獻頁在 320、390、768、1440px 的公開呈現，並驗證組織資料編輯與模擬奉獻流程。瀏覽器測試以合成的組織頁面回應驗證欄位轉換，不改寫共用資料庫的協會頁面。測試不會啟動真實金流、建立匯款資料或宣稱已開立收據。

## 執行前

- 使用已啟動的本機或 UAT 服務；預設網址為 `http://localhost:3180`，也可設定 `BASE_URL`。
- 設定合成驗收帳號的 `DEMO_PASSWORD`。不要在命令列歷程、文件或提交中寫入正式密碼。
- 確認服務含有合成管理員與會員帳號。測試會使用登入建立私有的模擬奉獻紀錄。
- 執行本驗收時不需遷移或重置共用資料庫；不要對正式服務執行。

## 執行

在 repository 根目錄安裝依賴並執行清單檢查：

```sh
npm ci
npm run test:e2e -- --list
```

服務已啟動且 `DEMO_PASSWORD`、`BASE_URL` 設定完成後，可執行官網改版 UI 測試：

```sh
npm run test:e2e -- tests/e2e/public-redesign.ui.spec.ts
```

截圖與失敗追蹤檔會寫到 Playwright 的 `test-results` 輸出目錄。截圖名稱包含頁面與視窗寬度，便於比較四種版寬。

## 驗收涵蓋

- 公開頁面無水平溢出，頁首與內容可在窄螢幕閱讀；登入後入口不會把管理連結當成公開導航呈現。
- 最新文章維持日期與文章連結。
- 組織頁面可保存層級、部門與同工資料，保留其他 metadata；公開 API 顯示已發布頁面，草稿不出現在公開列表或單頁查詢。
- 奉獻用途、預設／自訂金額、登入後返回、建立與確認模擬交易；成功、失敗、取消由 API 回應決定並以中文呈現。
- 建立請求處理期間停用重複提交。頁面不顯示銀行帳號、卡號欄位或收據承諾。

此流程僅供 UI 驗收。奉獻紀錄與模擬結果不代表實際收款、銀行入帳或稅務收據。
