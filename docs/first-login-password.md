# 首次登入更改密碼

後台帳號可帶有 `must_change_password=true` 狀態。登入回應及 `GET /auth/me` 都應提供此旗標；前端在登入後導向 `/change-password`，並在重新整理或直接開啟 `/app/**` 私人路徑時再次導回該頁。公開頁面仍可瀏覽。若私人 API 回應 403 且代碼為 `PASSWORD_CHANGE_REQUIRED`，前端導向密碼頁並保留登入工作階段；使用者仍可登出。

更改密碼表單要求目前密碼、新密碼及確認新密碼。新密碼至少 10 字元、不得與目前密碼相同，兩次輸入必須一致。驗證失敗時保留在密碼頁並顯示錯誤。成功呼叫 `PUT /auth/password` 後重新取得登入資料；當 `must_change_password` 為 false 時，導向該使用者一般工作台。註冊 OTP 流程建立一般帳號時，此旗標應為 false，不應要求首次登入改密碼。

驗收及範例只使用 mock API 與合成帳號；不要在文件或版本控制中保存真實帳號、初始密碼、OTP 或私人電話號碼。
