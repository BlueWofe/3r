Product lightbox pinch / pan acceptance — 2026-10-16 (Asia/Taipei)

Scope: image-only lightbox zoom from 1x to 4x, with one-finger panning after zoom. Original-size horizontal swipe continues to navigate photos. No backend, schema, permissions, or product-data change.

All browser /api/v1 requests use synthetic fixtures, including SVG image downloads, quote/cart and public guest-order responses. Product details are entered by client-side navigation to avoid bypassing browser interception with SSR. Homepage SSR can perform existing read-only public requests. No live account is used and no real database is seeded, reset, or written.

New focused suite tests/e2e/product-pinch.ui.spec.ts:
- Visible percentage and rendered image DOMMatrix scale / translation, rather than private Vue state.
- Accessible +/- controls clamp at 100–400%; reset, next slide, close/reopen and route disposal reset both zoom and pan.
- Modal Tab focus containment, Escape focus return and asynchronous native-dialog scroll restoration.
- Trusted Chromium CDP two-finger movement enlarges image dimensions, preserves visualViewport.scale=1, then trusted single-finger pan changes translation without changing the selected photo.
- Repeated pans stay within bounds; additional outward pinch clamps at 4x. Shrinking to 1x restores horizontal swipe navigation.
- Trusted two-to-one finger transition/cancellation and deterministic TouchEvent transition regressions never become accidental photo navigation.
- A portrait 600x1200 synthetic image at 320px checks actual object-fit:contain content bounds, rather than the wider CSS image box.
- No document overflow, unchanged global viewport settings, no browser-zoom prohibition, no page errors.

Browser coverage: desktop Chromium and mobile WebKit for controls, layout and synthetic cancellation; separate Chromium phone 390x844 hasTouch context for trusted CDP gestures. WebKit has no CDP equivalent. Browser emulation does not claim physical iPhone acceptance.
