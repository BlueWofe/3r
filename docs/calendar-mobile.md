# 行事曆行動操作

月／週曆以星期日開始，手機預設月曆。工具列的上一期、今天、下一期、議程、週、月保留在同一列；切換視圖不需要拖動橫向頁面。

日期格維持相同高度，最多顯示三條課程摘要，額外課程以數量提示。點選日期開啟當日清單，清單可捲動，選擇課程後開啟既有課程操作。狀態除了顏色也有文字說明，避免只依顏色辨識；資料異動後重新取得課程。

設計參考 [Apple：在 iPhone 更改行事曆事件檢視方式](https://support.apple.com/en-ie/guide/iphone/iphfd1054569/ios) 的精簡月份事件標記及列表檢視。此實作沿用網站本身的繁體中文、配色與權限規則。

驗收涵蓋 320px／390px 工具列單列、密集課程日期的固定格高、完整當日清單、課程操作、鍵盤關閉、星期日起始與跨月切換。
